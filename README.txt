GANESHVERSE READY
==================
This version is intentionally self-contained and does NOT require ganesha.glb.
It uses procedural Three.js models so the game can run immediately.

INSTALL/RUN:
1. Replace your old project files with this folder's contents.
2. Open PowerShell in the project folder.
3. npm install
4. npm run dev
5. Open the localhost URL shown by Vite.

Controls:
WASD / Arrow keys = move
E or click = interact

Stages:
1 Chanda Yatra
2 Choose Your Ganesha
3 Ganesha Arrival
4 Pandal Preparation
5 Ganesh Puja
6 Aarti
7 Grand Celebration

If you already have an old localStorage save and want a clean start, click START FESTIVAL.
